# Example Research Questions

Paste two or three relevant passages and their titles for each question. Use the original URL when available.

1. Should I build a narrow AI portfolio tool or a general assistant this month?
2. Which three capabilities do current engineering manager job postings emphasize most?
3. What are the strongest arguments for and against adopting a new AI coding tool for a small team?
4. How do two vendor announcements differ on data retention and pricing?

For a two-minute demo, use **Load example** in the UI. It supplies three fictional, clearly labeled personal sources and needs no API key.
